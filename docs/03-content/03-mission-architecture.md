Design Rules

1.

Mission must have one clear objective.

2.

Mission should focus on one communication skill.

3.

Mission should be short.

4.

Mission should feel like a game.

5.

Mission should always end with a reward.

6.

Mission should encourage speaking.

7.

Challenge mode should not have fixed answers.
